# Lexues QR 📷

Lexues QR me kamerë dhe foto — dekodim 100% në browser me jsQR, pa server, pa ngarkim të dhënash.

**Live:** https://erionnezha.github.io/QR-Code-Reader/

## Veçori

- 📷 Skanim live me kamerë (video + kornizë e gjelbër kur gjendet kodi)
- 🖼️ Ngarko foto nga pajisja — dekodim automatik
- ✅ Rezultati me butonat **Kopjo** dhe **Hap linkun** (vetëm për URL http/https)
- 📜 Historiku i skanimeve në `localStorage` + buton **Pastro**
- 😊 Mesazhe të hijshme kur kamera refuzohet ose mungon
- 📱 Responsive, UI plotësisht në shqip

## Si përdoret

Tabi **Kamera**: shtyp *Fillo skanimin*, lejo kamerën dhe drejtoje nga kodi.
Tabi **Ngarko foto**: zgjidh një imazh që përmban kod QR.

*Shënim: kamera kërkon lidhje të sigurt (https). Faqja është live në https, kështu që funksionon.*

I gjithë kodi (HTML, CSS, JavaScript) shfaqet në faqen live, në seksionin **💻 Kodi Burim**.
